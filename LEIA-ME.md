# Página de vendas: Como ser promovido (Método PONTE), R$ 297

No ar: https://como-ser-promovido-carlos.vercel.app

React + Vite + Motion. Mesma identidade da página do livro (navy, azul, amarelo, Outfit e Manrope).
Estrutura baseada na página SPE da Luana Carolina: promessa que mata objeções, prova logo no topo, etapas com "Resultado esperado", bônus com valor, recapitulando, garantia, FAQ.

Tudo que muda sem mexer no layout fica em src/config.js (checkout, WhatsApp, CNPJ, depoimentos, preço).
Textos em src/components/Sections.jsx. Pasta dist/ é o site compilado.

Publicar: vercel --prod (sem npm install local).
